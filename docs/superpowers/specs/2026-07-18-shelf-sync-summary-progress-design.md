# 书架强制同步摘要进度设计

## 目标

在书架已有缓存时，点击“强制刷新书架”后，在 summary 统计区域显示同步阶段和进度；同步完成或失败后移除进度展示。同步过程中不得因为每本书的进度事件而重建整个书架 DOM。

同时将“同步”和设置按钮统一为 30×30px，并使用主题的强调色变量，确保不同 Obsidian 主题下文字和背景保持足够对比度。

## 交互设计

1. 点击“强制刷新书架”后，保留当前书架内容，并在 summary 统计栏下方显示进度区域。
2. 进度文本复用现有同步进度 view model：获取阶段显示等待文案，enriching 阶段显示“正在加载书籍 x/y”，保存和完成阶段显示对应状态。
3. 有确定数量时显示 determinate progress；获取阶段或总数为零时显示 indeterminate progress。
4. 同步完成或失败后，执行一次完整刷新并移除进度区域；已有缓存继续保留。
5. 未配置 API Key 的行为保持不变：不发起请求并提示配置 API Key。

## 实现方案

- 在 `ShelfView` 中增加 summary 进度元素引用。
- `renderStats()` 在 `isLoading` 且存在缓存时创建进度区域。
- `updateSyncProgress()` 在已有缓存时只更新进度文本、`max`、`value` 和 indeterminate 状态，不调用 `renderContent()`；无缓存首次加载仍使用现有轻量 loading 渲染。
- `syncAndRender()` 的最终刷新负责清除 summary 进度元素，保证成功和失败路径一致。
- 在 `styles.css` 中增加 summary 进度布局样式，并让同步按钮复用设置按钮的尺寸、圆角、图标尺寸和主题强调色/悬停色。
